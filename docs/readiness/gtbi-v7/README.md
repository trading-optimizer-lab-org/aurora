# GTBI V7 Readiness Bootstrap

This directory is the pre-genesis candidate area for the GTBI V7 readiness
state. It is not evidence that `PREV7-0000` or any gate is complete.

## Current State

`master_plan_quality_status.json` is authoritative for the candidate generated
from the current bytes. Its current state is `BLOCKED` and execution remains
`NO-GO`.

The deterministic local checks prove only that:

- the master-plan bytes are UTF-8, LF-only and final-LF canonical;
- the task matrix contains 110 unique tasks;
- dependencies and the 15-gate graph are known and acyclic;
- all 110 tasks have a gate and one of the 46 priority steps;
- Markdown fences, tables, URLs and frozen forbidden-term rules pass;
- the canonical serialization profile, domain registry and audit scope can be
  regenerated byte for byte.

They do not replace independent review.

## Missing External Inputs

The following files must be imported byte for byte from the external bootstrap
transaction before the signed quality job can pass:

```text
master_plan_quality_receipts.jsonl
master_plan_quality_receipt_set.json
master_plan_audit_trusted_keys.json
```

There must be exactly three sequential, non-overlapping `CLEAN` receipts.
Auditor actor IDs and Ed25519 signing-key IDs must be pairwise distinct. No
auditor may be the document author or implementer. Each signed independence
attestation binds the complete audit report, structural-validation report and
identity evidence by SHA-256.

The receipts must all bind the exact identities currently recorded in:

```text
master_plan_audit_scope_manifest.json
master_plan_quality_status.json
```

Changing one byte of the master plan, canonical profile, domain registry,
scope manifest, report, identity evidence or receipt invalidates the package.

## Commands

Regenerate deterministic candidate files:

```powershell
C:/Python314/python.exe scripts/generate_gtbi_v7_bootstrap_contracts.py
```

Run focused tests:

```powershell
C:/Python314/python.exe -m pytest tests/test_gtbi_v7_readiness_bootstrap.py -q
```

Validate the external quality package after it has been imported:

```powershell
C:/Python314/python.exe scripts/validate_gtbi_v7_master_plan.py
```

Exit status `0` means `CLEAN`, `1` means invalid evidence and `2` means
required external evidence is still missing.

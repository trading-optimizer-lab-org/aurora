deterministic structural check and the repository owner's simplification

owner-controlled model while retaining automated checks, cost limits and
scientific boundaries.

## Retired External Audit Package

The following historical files are optional compatibility artifacts:

```text
master_plan_quality_receipts.jsonl
master_plan_quality_receipt_set.json
master_plan_audit_trusted_keys.json
```

They are not required and their absence cannot block a task or gate. Current
acceptance binds the exact identities recorded in:

```text
master_plan_audit_scope_manifest.json
master_plan_quality_status.json
owner_simplification_directive.json
```

Changing one byte of the master plan, canonical profile, domain registry,
scope manifest, report, identity evidence or receipt invalidates the package.

Each auditor validates their report against:

```text
config/gtbi/schemas/v7/operational/master_plan_quality_audit_report_v1.schema.json
```

The auditor then runs
`scripts/create_gtbi_v7_master_plan_audit_receipt.py` in their own controlled
environment with their own Ed25519 key. The command emits one receipt, one
structural report and one public-key record. It never creates an identity,
finding result or key.

The old receipt creation and assembly scripts remain only to read or reproduce
historical evidence. They are outside the current acceptance path.

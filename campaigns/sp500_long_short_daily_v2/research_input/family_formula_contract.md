# Frozen family and formula contract — V2

## Universal notation

- `P_t`, `O_t`, `H_t`, `L_t`: split-normalized **price-only** SPY close, open, high and low for session `t`.
- `V_t`: split-normalized SPY share volume.
- `r_t = ln(P_t/P_(t-1))`.
- `r_on_t = ln(O_t/P_(t-1))`.
- `r_id_t = ln(P_t/O_t)`.
- `Q_{symbol,t}`: split-normalized price-only close for a fixed predictor ETF.
- All windows end at `t`. No centered window, full-sample estimate or future backfill is permitted.
- A strictly positive score emits/sets `+1`; a strictly negative score emits/sets `-1`.
- Equality, zero score, unavailable score or no event preserves the previous state.
- Initial state is `+1` until the first eligible directional event.
- Decision: after SPY close `t`; execution: next tradable SPY open `t+1`.
- Target P&L uses the audited V1 SPY total-return open-to-open ledger. Predictor-ETF ratios are price-only and exclude distributions deliberately.

## Shallow-tree timing

For `causal_shallow_tree`, a training label for decision date `s` is known only after the SPY opening that ends the corresponding `open(s+1) → open(s+2)` return interval. At close `t`, the fit may contain only labels whose ending open has occurred. The first session of each calendar month triggers the deterministic refit; all remaining sessions use the latest lawful fit.

## Prohibited reinterpretations

Codex must not:

- replace price-only predictor ratios with total-return ratios;
- replace audited target total return with raw close returns;
- reverse signs based on train outcomes;
- add neutral/cash states;
- insert thresholds, smoothing or winsorization absent above;
- use retrospective break dates for CUSUM;
- tune tree hyperparameters, features, refit frequency or minimum sample;
- synthesize pre-inception ETF observations;
- change missing-data persistence into position zero.
